A comprehensive Enterprise Resource Planning (ERP) system custom-built for automated inventory management, billing, and operational traceability. Originally developed as an engineering thesis project and successfully deployed in production for a commercial enterprise (Marnys, Honduras).

🔗 **[Live Production Environment: marnystock-app.vercel.app](https://marnystock-app.vercel.app)**
*(Note: Access may require authorized credentials).*

## ✨ Business Impact & Features
* **Process Automation:** Streamlined critical operational workflows, completely digitizing inventory tracking and sales processing.
* **Measurable Efficiency:** The implementation of this system successfully reduced administrative reconciliation times by 57%.
* **Advanced Billing Module:** Custom logic for handling special customer pricing tiers and automated invoice generation.
* **Real-time Dashboard:** Built a comprehensive analytics dashboard for instant visibility into stock levels and sales metrics.

## 🛠️ Architecture & Tech Stack
* **Frontend Development:** React.js, JavaScript (ES6+), HTML5
* **UI/UX Design:** Tailwind CSS (Responsive, mobile-first approach)
* **Backend Integration:** Built with a scalable BaaS architecture (Firebase).
* **Build Optimization:** Vite

## ⚙️ Project Context

This repository showcases the frontend architecture of a full-scale B2B solution. It demonstrates the ability to translate complex business requirements into a functional, highly optimized, and maintainable software product.
